# One button for a missing with an address

## Context

When a missing **Finding** named a **Stretch**, the correction screen offered a single
microphone that walked both stations of the **Long way**, while the visual it wore belonged
to neither. The question put was whether to keep one button and give it the **Long way**'s
own look, or to bring back the two the room had before.

## Considered Options

Two buttons — one for the **Short way**, one for the **Long way** — so the team could pick
which voice speaks again. Rejected in the product owner's own words: only the button
carrying both microphones, otherwise it confuses.

## Decision

One button, wearing the **Long way**'s visual: amber, with the small blue underneath, so the
screen shows both stations before the team commits to either.

## Consequences

The **Short way** stopped being reachable from a missing that named a **Stretch**. That is
what made the decision short-lived: a day later the product owner reopened the question —
a gap in the content need not mean the recording was wrong — and the answer reversed. The
single-microphone screen was removed and both microphones came back, which is ADR 0005.
Kept here because a reader finding the grid may otherwise reopen the same question a third
time.
