# Only a missing past the last stretch returns to the Rehearsal

## Context

A missing **Finding** can mean two unrelated things: the team explained a **Stretch** badly,
or the team never recorded that ground at all. The **Analyst** distinguishes them by the
address it attaches, and the room has to route on that distinction, because the two answers
cost very different amounts of the team's work.

## Considered Options

Sending every missing back to the **Rehearsal**. Rejected because that path is destructive
and destructive on the server too: one session had all five of its segments retired by it.
A gap in the middle of the story must never reach the **Rehearsal**.

## Decision

A **Missing with an address** goes to the correction screen that asks where the error
lives. A **Missing without an address** — one pointing past the last **Stretch** told —
returns to the **Rehearsal** with every **Take**, **Stretch** and **Bead** kept, so the team
records the ground the **Passage** still lacks; on the next pass only the new stretches are
counted.

## Consequences

The whole distinction rests on the address the **Analyst** attaches, which is prompt
behaviour rather than code. When it misaddresses, the cost is measured in the team's
recordings: a gap addressed to a told stretch instead of past the end made a team overwrite
a stretch that was already right, and then re-tell the one after it.
